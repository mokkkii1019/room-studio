## 1. `/try` — スマホ30秒ミニ体験

`https://roomstudio.jp/try`

サンプルの部屋の**壁と床の色をタップで切り替え**、**家具を置く/外す**、**変える前と見比べる**
だけに絞った超軽量ページ。アプリ本体（319KB）は読み込まない。

- **初回表示の転送量 約75KB**（HTML gzip 8.7KB ＋ 写真 66.4KB）。Webフォント・CDN・外部JSはゼロ
- GA4イベント: `try_view` / `try_color_change` / `try_before_after` / `try_furniture` /
  `try_cta_click` / `try_copy_url`
- スマホでは「PCで開くとフル機能」の案内とURLコピーを表示
- 商品リンクは `TRY_PRODUCTS` が空のため非表示（運営が実在の商品を入れると出る）

**本番実測**: 壁4面すべて着色／床のみ暗化（L0.749→0.576）／天井・窓は不変／
面ごとの明暗順序を保持／BEFOREで初期に復帰／横スクロールなし。

## 2. `/demo` — 自動デモモード（録画用）

**開くだけで「変身」が自動再生される**ページ。運営は画面録画を回してURLを開くだけでよい。

### 🎬 録画手順（これが本題）

1. 画面録画（Windows: `Win`+`G` / Mac: `Shift`+`Cmd`+`5` / スマホは標準の画面収録）を開始
2. ブラウザで下のURLを開く。**開いた瞬間から再生が始まり、指定秒数でループ**する
3. 1周ぶん（15秒 or 30秒）録れたら停止

**ブラウザは全画面（F11）にし、`clean=1` を付けるのが基本**です。ツールバーやカーソルが
映り込まず、そのまま素材として使えます。

| 撮りたいもの | URL |
|---|---|
| **ショート動画（縦型・15秒）** ← 主戦場 | `https://roomstudio.jp/demo?len=15&ratio=9x16&clean=1` |
| ショート動画（縦型・30秒） | `https://roomstudio.jp/demo?len=30&ratio=9x16&clean=1` |
| X / YouTube 用（横型・15秒） | `https://roomstudio.jp/demo?len=15&clean=1` |
| 横型・キャプション入り（説明用） | `https://roomstudio.jp/demo?len=15` |
| テイスト違いを量産する | 上のURLに `&preset=natural` / `&preset=grey` / `&preset=green` |

### 再生される内容（総尺に対する比率で刻むので15秒でも30秒でも同じ構成）

| 位置 | 内容 |
|---|---|
| 0% | BEFORE（もとの部屋・家具なし） |
| 17% | AFTER に切り替わり、家具が入る |
| 27% | 壁の色が変わる |
| 40% | 床の色が変わる |
| 55% | 壁・床が2パターン目へ |
| 72% | 壁・床が3パターン目へ |
| 88% | BEFORE に戻る（対比を見せる） |
| 94% | AFTER に戻って締め |

### パラメータ

| パラメータ | 値 | 既定 | 効果 |
|---|---|---|---|
| `len` | `15` / `30` | `15` | 1周の長さ（秒） |
| `ratio` | `16x9` / `9x16` | `16x9` | 縦型はショート動画用のレターボックス |
| `clean` | 任意の値 | なし | 見出し・バッジ・ブランド・グラデを全部隠して**部屋だけ**にする |
| `preset` | `natural` / `grey` / `green` | `natural` | 再生する配色の組み合わせ |

### 検索エンジンから隠す（三重）

1. ページに **`<meta name="robots" content="noindex, nofollow">`**
2. レスポンスヘッダに **`X-Robots-Tag: noindex, nofollow`**
3. **`robots.txt` に `Disallow: /demo`**、かつ **sitemap.xml に載せない**

認証は掛けていません（指示書どおり「URLを知っている人だけが使う」想定）。

## 3. 検証結果

### `/demo` のタイムライン

仮想時間で `requestAnimationFrame` を回すと Chrome の仮想クロックが進まず観測できないため、
rAF を `setTimeout` に差し替えた**同一のタイムライン判定**で計測した。実時間での再生は
実ブラウザで確認が必要（録画時に運営が確認できる）。

| 経過 | 状態 |
|---|---|
| 2秒 | BEFORE・もとの白壁とオーク床・家具なし |
| 7秒 | AFTER・生成りの壁・家具あり |
| 11秒 | 淡いグリーンの壁＋ウォルナットの床 |
| 20秒（2周目） | **色がリセットされて生成りから再開**（ループが正しく巻き戻る） |

ループ先頭で色を戻す処理は、実装中に**必要と分かって追加**した。入れないと2周目以降の
AFTER が前の周回の最終色から始まり、「変わっていく」感じが出なかった。

### レイアウト

16:9・9:16・`clean=1` の3モードをレンダリングして確認。16:9 でキャプションが枠外へ
押し出される不具合を見つけ、**下部オーバーレイ＋暗いグラデーション**に変更した。

### リグレッション

`/try` の描画エンジンを `/demo` と共有するため `ROOM_ENGINE_JS` に切り出したが、
切り出し前後で `/try` の実測値が**完全に一致**することを確認済み
（壁 200,201,198→203,213,202 など全項目）。ページは 24.6KB → 21.5KB に縮んだ。
